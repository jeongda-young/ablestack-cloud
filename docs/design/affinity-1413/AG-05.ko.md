# AG-05: VM 표준에 맞춘 Affinity UI 정돈

대상 #1418, Epic #1413, 누적 Draft PR #1420. Europa `d9f068bbbba048313b6d38539651d19444c4d7c7`와 AG-04 완료 커밋 `1001c6d5d403bf56c425b78549e460fc41eea718`에서 이어 구현한다.

## 비교 기준과 변경

| 영역 | VM 기준 | Affinity 적용 |
| --- | --- | --- |
| 목록 | AutogenView/ListView의 도구·검색·열 선택·페이지·우클릭 | 공통 구조 유지, 같은 크기 표, 긴 값 감싸기·빈 설명·가로 스크롤, 정책 한글 표시 |
| 상세 | ResourceLayout/InfoCard/DetailsTab과 UUID 복사·소유자 링크 | 공통 카드 유지, 같은 유형 문구·정책 설명·전체 연결 수, 기존 계정/프로젝트/도메인 링크 보존 |

범용 UI 변경은 Affinity 경로/컴포넌트에 한정한다. VM Affinity 변경창 자체는 같은 MoldDialog(lg)로 통합하고 Autogen의 중첩 모달을 제거한다. 다른 VM 작업창의 기능 계약은 변경하지 않는다.

## 문구와 필터

API 유형 원문은 그대로 전송한다. 4개 배치 유형을 같은/다른 호스트, 엄격/선호 의미로 표시하며 상세/생성 폼에 설명을 제공한다. 알려지지 않은 유형은 원문을 유지하고 알려진 정책으로 오인하지 않는다. 전용 자원 유형은 별도 설명을 사용한다.

AG-D07의 `affinitygroupid` 필터는 한글 제목과 권한 범위 내 그룹 이름을 표시한다. UUID는 툴팁에 보존하고 삭제/조회 불가 시 식별자로 대체한다. 필터·프로젝트·로그인 변경 시 이름을 즉시 비우고 최신 요청만 반영한다. 그룹의 관련 VM 링크는 프로젝트 ID를 유지한다.

## 접근성·화면 크기

상태는 색과 한글 텍스트를 함께 제공한다. 검색/선택·표 영역을 이름으로 구별하며 표 영역에 키보드 초점을 둘 수 있다. 가로 스크롤은 표 안에 두고 페이지/작업 버튼은 화면 안에서 감싼다. 대화상자 본문만 세로 스크롤하며 하단 버튼을 유지한다. 긴 이름·설명·job ID는 감싸고 의미를 잃지 않는다. 생성 오류는 해당 입력으로 초점을 옮기고 입력을 보존한다.

390×480에서 크기 변경 후 고정 도구 모음 래퍼의 투명한 하단 영역이 탭 중앙을 가리는 결함을 실제 포인터와 hit test로 재현했다. Affinity 경로에서 래퍼는 입력을 통과시키고 실제 도구 모음 카드만 입력을 받도록 제한한다. 탭 중앙의 포인터 대상과 클릭 후 활성 탭을 함께 검증한다.

모바일의 긴 이름은 breadcrumb에서 말줄임해 고정 헤더가 짧은 화면을 차지하지 않게 한다. 원래 이름은 접근성 텍스트와 요약 카드/상세에 유지하며, 긴 이름 그룹에서도 탭과 콘텐츠를 실제로 조작한다.

긴 이름/설명 때문에 자동 열 너비가 다른 열을 좁히지 않도록 정렬 헤더에 최소 너비를 두고 헤더와 VM 상태 문구는 한 줄로 유지한다. 추가 가로 공간은 기존 표 내부 스크롤로 제공한다.

실제 31번 UI에서 라이트/다크와 1440×900, 390×844, 390×480을 비교한다. 전용 다중 페이지 그룹/Stopped VM과 일반 사용자·프로젝트를 사용하며 기존 자원은 읽기 기준선으로 보존한다. 생성 실패 수정, 멤버 연결/해제·오류 재시도·결과 재열기, 삭제 영향, Back 탭/프로젝트를 UI/API/DB로 확인한다.

## 경계

배치 문맥·작업 잠금·최신 연결 병합·영수증 불명 재전송 금지·삭제 재확인을 유지한다. AG-04의 CAS 없는 전체 연결 교체 API와 앱 재로드 영수증 제한은 변하지 않는다. 실제 배치 정책/전체 역할·통합 경로의 최종 합격은 #1419에서 담당한다. 배포는 정적 UI에 한정하고 WEB-INF·설정·JAR·PID를 보존한다. 전체 Cloud 빌드는 실행하지 않는다.
