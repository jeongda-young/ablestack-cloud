# AS-03 카운터·기간·정책 평가 설계 (#1349)

대상: Epic #1346 / 누적 PR #1356. 현재 단계: 구현·변경 모듈 빌드·31/32 배포·해당 범위 실제 UI 검증 완료. [검증 기록과 제한](AS-03-validation.ko.md)을 참조한다. 기존 AS04 그룹을 보존하며 다른 하위 이슈 구현에는 착수하지 않는다.

## 소스 확인 결과

기간에 1024ms/초, 모니터 비교에 초/ms 혼용이 있다. 평균을 낼 때 전체 기간·최근 수집·현재 멤버 전체의 샘플을 확인하지 않는다. VR 통계 조회 실패가 0으로 반환될 수 있고 LB의 그룹 연결 합계를 VM 평균으로 정규화하지 않는다. 정책 순서와 쿨다운이 반대 방향 및 공유 정책의 그룹 간 영향에 취약하다. 기존 AS04에서 같은 방향의 모든 정책 갱신은 보완했으므로 초기 이슈의 첫 정책만 갱신 결함과 현재 소스를 구분한다.

## 평가 계약

- 모든 초→밀리초는 TimeUnit을 사용하고 정수 입력/양수 duration·interval, 음수 quietTime을 검증한다. duration은 그룹 interval 이상이어야 한다.
- 전체 duration의 관측 구간이 쌓이고 최신 샘플과 현재 멤버 전원이 확인돼야 평가한다. 시간 순으로 정렬하고 같은 자원/시각 중복은 한 번만 사용한다. 큰 수집 공백·누락·비활성/dummy·비정상/미래 값은 해당 정책을 보류한다.
- CPU/메모리는 같은 수집 시점의 현재 VM 평균, VR 네트워크는 누적 메가비트 차분/초/현재 멤버 수, LB는 규칙의 현재 연결 합계/현재 멤버 수다. 각 시점의 값이 연속 관측 기간 동안 연산자를 만족해야 한다. 누적 카운터 감소·타입/활성 라우터 변경은 재수집 기간이 확보될 때까지 보류한다.
- 한 정책의 조건은 AND, 같은 방향의 정책은 OR, 동시에 맞으면 확장 우선이다. 확장 판단이 데이터 불확실로 보류되면 축소도 보류한다. min/max는 AS04 작업 소유권의 최신 검사로 다시 보호한다.
- 성공한 증감 완료 시 그룹별 last-scaled를 기록한다. 관련 모든 정책의 가장 긴 quietTime 동안 양 방향 모두를 보류하여 공유 정책과 그룹 간 쿨다운을 분리한다. 멤버 변경 뒤 새 duration의 데이터를 확보한다.
- KVM 오토스케일 전용 VR 읽기는 조회 실패를 0으로 만들지 않는다. 부재 값은 누락으로 전달하고 서버가 INACTIVE로 기록한다. KVM 메모리는 balloon.last-update가 호스트 설정 수집 주기의 2배 이내인지 확인한다. 통계 정리는 duration+2*interval 경계 표본을 보존한다. Mbps는 1,000,000bit/s, 연결은 VM당 평균으로 통일한다.

## 현재 Mold UI

기존 상세 탭에 최근 평가 카드/Alert를 추가한다. 서버가 기록한 평가 시각·수집 시각·판정/보류 사유·정책·카운터별 값/단위/표본 수를 표시한다. 네트워크 값은 그룹 밖의 공유 VR 공인 인터페이스 트래픽을 포함함을 명시한다. 호스트/VR를 브라우저에서 직접 조회하지 않는다. 상세 정책에서도 생성/API와 같은 GT/GE/LT/LE/EQ를 제공하고 초/단위·오류를 한글로 안내한다. 기존 테마 토큰과 반응형 공통 컴포넌트를 사용한다. 전체 VM UI 표준 통합은 #1355로 유지한다.

최신 평가 기록은 MEDIUMTEXT 명시 길이로, 평가/그룹별 last-scaled 시각은 BIGINT 밀리초로 저장하며 Europa 멱등 마이그레이션으로 추가한다. 기존 날짜 값은 쿨다운이 짧아지지 않게 보수적으로 올린다. API는 기존 그룹 ACL 아래 공개 UUID·집계와 안정된 사유 코드만 반환하며 내부 VM/호스트 id나 인증 값을 노출하지 않는다.

## 검증 계획

MET-01~10: 가짜 시계의 60초 전/정각/후·interval·quietTime·int 상한, 5개 연산자·AND/OR/우선순위, VM 누락/빈·오래된·비활성/더미 샘플, 카운터 초기화/정렬/중복, CPU/메모리/VR 단위·분모와 실제 수집 경로를 검증한다. 변경 API/Schema/Server/KVM 모듈 및 UI만 빌드한다.

31 GFS2 Sparse(Thin 금지)와 32 krbd에서 UI로 설정하고 실제 정책/부하 결과와 새 진단 표시를 대조한다. 메모리 balloon 수집 조건, VR 네트워크·LB 및 라우터 재시작을 확인한다. 한국어·밝은/다크·일반 사용자/프로젝트를 검증하고 API/DB/호스트 증거로 보강한다. 실패 주입은 전용 그룹으로 제한하며 최종 DISABLED/VM1을 보존한다. 장시간 운영은 #1354 마지막 단계다.

참고: [CloudStack 공식 duration/quietTime/카운터 범위](https://docs.cloudstack.apache.org/en/latest/adminguide/autoscale_with_virtual_router.html). 실제 동작은 이 fork와 두 클러스터에서 대조한다.
