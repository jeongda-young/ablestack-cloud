# AS-07 운영 가시성 설계 (#1353)

상위 Epic #1346, 누적 Draft PR #1356. 기존 Mold ResourceLayout 및 공통 표/상태 컴포넌트를 사용한다. 다음 #1355의 메뉴 전체 UI 통합은 별도 진행한다.

## 확인한 문제

1. availablevirtualmachinecount는 Running/Starting/Stopping/Migrating 합계이므로 서비스 정상 수로 사용할 수 없다.
2. 기록된 멤버의 정지/오류/삭제 대기와 LB 등록을 한 화면에서 대조할 수 없다. DISABLED는 정책 중지이며 이미 수락한 정리 작업 중지와 같지 않다.
3. 과거 평가가 현재 정책과 다르거나 오래된 경우 시각과 출처를 명확히 제시해야 한다. 손상된 평가 JSON 때문에 그룹 조회 전체가 실패해서는 안 된다.
4. 운영 조회 일부가 실패하면 실패한 자료의 마지막 표시를 보존하고 출처별 조회 시각·오류·권한 없음·빈 결과를 구분해야 한다.

## 구현 계약

- listAutoScaleVmGroups의 기존 ACL/프로젝트 범위를 유지하며 memberstatecounts/statuscollectedat/lastscaledat/lastcheckedat/operationdeadline/evaluationerror를 추가한다. 한 SQL 집계로 VM 상태 및 Removed/Missing 잔여 매핑을 확인한다. 신규 권한/API/DB 컬럼은 추가하지 않는다.
- VM Running은 Cloud 상태이며 애플리케이션 상태가 아니다. LB API의 등록과 servicestate는 설정 적용 정보이며 HTTP 연결 성공 보장이 아니다. 게스트/호스트/VR 직접 접속은 UI에서 하지 않는다.
- 운영 상태 탭에서 기존 listVirtualMachines(그룹 필터/페이지/검색), listLoadBalancerRuleInstances, listEvents(그룹 resourceid/resourcetype)을 각각 기존 API 권한으로 조회한다. 숨겨진 VM 상세·프로필·UserData·SSH 키·API 비밀·내부 operation token은 표시하지 않는다.
- 마지막 자동 조정 성공은 기존 lastScaled 기반이며 관리자 enable/disable 성공 이벤트와 구분한다. 오류 단계는 자동 재조정 대기와 후속 확인 안내를 표시하며 재전송 버튼을 만들지 않는다. 이벤트 UUID/parent UUID 링크로 상관관계를 확인한다.
- 수동 부분 새로고침/탭 유지/검색·페이지 유지, 요청별 순서 번호와 종료 시 무효화, 출처별 기존 데이터 보존을 적용한다. 자동 타이머는 추가하지 않는다.
- 최근 평가의 경과·정책 변경/삭제 후 과거 기록·알 수 없는 상태·잘못된 날짜를 명시한다. 수집 실패를 숫자 0으로 해석하지 않는다.
- 한국어/영어 라벨과 현재 Mold 테마 토큰을 사용하고 실패·대기·미등록을 색상 외 텍스트로 표현한다.

## 검증 계획

- API 응답 계약/손상 평가, 집계 SQL의 실제 31/32 DB 대조, 최근 성공·드레인 시각의 ms 정확성.
- UI 응답 역전/부분 실패/권한 부재/검색·페이지/리소스 변경/컴포넌트 종료 계약 테스트.
- 31 프로젝트 사용자(GFS2 Sparse)와 32 일반 사용자(krbd): 비활성/활성/확장/연결 유예/삭제 실패·자동 재시도/정지 VM/멤버 LB 제외 표시를 실제 UI로 확인한다. 전용 검증 VM과 조작만 수행하고 기존 3/4 그룹·원본 VM을 보존한다.
- 제한 역할에서 기존 허용 목록만 조회하고 다른 소유자·프로젝트 접근은 기존 ACL로 거부되는지 확인한다. 라이트/다크와 한글·빈/지연/오류 표시를 확인한다.
- Epic MET-01~10은 기존 AS-03 수집/계산 계약 회귀 및 해당 화면 표시 범위로 검증하고, ASY-08~10은 기존 생성 복구 기능 회귀/관찰 범위로 검증한다. 장시간 운영은 #1354 최종 단계에 남긴다.
- 변경 api/engine-schema/server 모듈 및 UI만 빌드한다. 전체 Cloud/Actions 빌드는 실행하지 않는다.

## UI 검증 중 추가 확인한 새로고침 결함

로그인 직후 새로고침해 세션은 남고 API 캐시·메모리 loginFlag가 없는 경우 GetInfo가 resolve/reject를 하지 않아 라우터가 빈 화면에 머물렀다. 실제 31/32 화면에서 재현했고, 동일 경로의 회귀 테스트 2개도 수정 전 시간 초과로 실패했다. 캐시가 없으면 인증된 listApis를 다시 조회하도록 수정한다. 세션 만료·권한 오류는 기존 실패 경로로 반환하고 선택 기능 조회가 로그인 완료를 지연하지 않는 기존 계약을 유지한다.

### 실화면 날짜 렌더링 회귀 수정

31·32번 실제 운영 탭에서 날짜 플러그인의 컴포넌트 수신자(`this`) 유실로 `$store` 조회가 실패하는 오류를 재현했다. 요약·평가·운영 탭의 포맷터를 컴포넌트에 바인딩한 호출로 수정하고, 사용자 시간대 설정을 읽는 회귀 테스트 3개를 추가한다.

### 한글 상태 번역 회귀 수정

현재 Mold의 flat locale에서 `$t`는 번역을 반환하지만 `$te`의 존재 판정이 false로 반환되어, 알려진 평가 상태가 알 수 없음으로 표시되고 LB 미등록도 등록됨으로 잘못 표시되는 UI 오류를 재현했다. 평가·LB·이벤트의 동적 상태는 실제 번역 결과로 존재를 판정하고, 미래 상태만 원문 코드와 함께 안전하게 표시한다. 알려진 평가·미등록/적용 LB·이벤트 한글 회귀 테스트를 추가한다.

### 링크 텍스트 대비 보완

배포 UI에서 운영 탭 텍스트의 대비를 측정했다. 다크 모드는 최저 4.58:1이었지만 라이트 멤버 링크는 기존 기본 파란색으로 3.24:1이었다. 운영 탭의 링크는 현재 Mold의 본문 색상 토큰과 밑줄을 적용해 테마별 대비와 비색상 구분을 함께 유지한다. 최종 배포본에서 다시 측정한다.
