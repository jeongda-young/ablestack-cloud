# AS-09 / #1355 Mold VM UI 표준 통합 설계

Epic #1346의 기존 기능을 현재 Mold에 통합한다. AS-01~07 API/평가/복구/프로필/예약/조회 계약은 유지하며 별도 대시보드나 UI를 만들지 않는다.

## 공통 탭과 전용 정보의 경계

공통 첫 상세 탭은 자원 속성 목록만 담당한다. 여기에 들어간 오토스케일 운영 요약·정책 평가·작업 알림을 제거한다. 이미 같은 요약·평가가 있는 전용 **운영 상태** 탭으로 단일화한다. 삭제 재시도·드레인·비활성화 후 정리 알림은 그 요약 안에서 표시한다. 새로운 요약 탭을 추가하지 않는다.

**EventsTab / AnnotationsTab 소스·탭 설정·형식은 그대로 유지**한다. 운영 상태의 최근 5개 이벤트는 기존 AS-07 조회 기능이며 공통 이벤트 탭을 대체하지 않는다. 모든 권한 판정과 부분 조회 실패/이전 기록 표시는 유지한다.

## 목록·왼쪽 요약

기존 ResourceLayout / InfoCard / ListView / 상태 표시 / 검색·정렬·선택·페이지를 재사용한다. 오토스케일 경로에서만 멤버(조정 대상 수와 최소·최대), 네트워크(LB 공인 IP와 공인→게스트 포트), 최근 확인(평가/작업 상태)을 묶어 표시한다. 기존 저장 열 선택은 새 열로 변환하며 API 원본 값은 바꾸지 않는다. 계정·프로젝트 범위는 기존 계약을 따른다. 왼쪽 공통 카드의 기존 details 슬롯에만 해당 그룹의 범위·포트·확인 시각을 추가한다. 다른 자원의 슬롯 출력은 비어 있으며 공통 카드 본문은 수정하지 않는다.

## 전용 탭·대화상자·생성

VM에서 사용 중인 mold-dialog 셸과 테마 토큰을 적용한다. 긴 폼의 확인/취소는 스크롤 본문과 분리한 고정 footer에 배치한다. 기존 프로필·정책·LB 변경의 권한·작업 중 차단·최신 상태 확인·공유 영향/실패 보상 로직을 유지한다. 기본 텍스트 작업 버튼이 먼저 나오고 보조 아이콘이 뒤따른다. 생성은 기존 VM 방식의 폼/요약 카드와 단계별 결과를 유지하고 그룹 범위·간격·LB 포트와 호스트 이름 제한을 최종 요약에 추가한다. UserData 원문·인증 정보를 요약에 노출하지 않는다.

재조정 대기 시간(초), 조건 추가, 조정 대상 VM 용어는 오토스케일 전용 키로 교정한다. 공통 이벤트·코멘트·다른 자원 번역은 변경하지 않는다.

UI 모듈과 실제 공유 이미지 생성 시험에서 발견한 API/server 모듈 변경만 빌드/배포한다. 전체 Cloud 빌드는 실행하지 않는다. 정적 배포는 WEB-INF/META-INF/config.json/PID를 보존하고 파일 SHA 및 /client/ 200을 검증한다. API/server 배포는 이전 JAR를 백업하고 변경 클래스만 갱신한 JAR로 관리 서비스를 재시작하여 검증한다. GitHub Actions 전체 CI와 장시간 운영은 본 이슈 검증 결과에 포함하지 않는다. #1354에서 통합 검증 후 최종 장시간 확인을 수행한다.

## 기존 후속 항목

현대식 생성 화면에 오토스케일 전용 공유 템플릿 분류를 기존 OS 선택 블록으로 추가한다. 별도 공통 VM 선택기 구조는 변경하지 않는다. `sharedexecutable`을 같은 소유 범위·Ready·Zone으로 조회하며 해당 분류의 검색·페이지는 독립 유지한다. 프로젝트의 정확한 ID API는 개인 계정 ACL로 판정하는 기존 문제가 있어, 생성 사전 검증은 같은 프로젝트·Zone·Ready의 최신 executable/sharedexecutable 허용 목록을 페이지 단위로 확인하고 선택한 ID만 반환한다. 권한 오류는 그대로 전달하며 다른 소유 범위로 조회하지 않는다. 개인 계정은 executable ID 결과가 없을 때 sharedexecutable ID를 확인한다. 프로필 저장 후 닫기/갱신은 AS-06에서 반영된 콜백을 이번 실제 UI에서 재확인한다.

## 첫 배포 UI에서 확인한 보완

네트워크 링크 중복과 프로젝트 소유자 공백, LB 선택기의 개수/로딩 prop 누락을 수정한다. 라이트 경로 표시, 비활성 버튼 내부 span, 생성 폼 오류/필수 표시와 단계 숫자의 실제 낮은 대비를 오토스케일 테마 토큰으로 교정하고 최종 번들에서 재검증한다. 공통 자원 화면의 CSS/형식을 바꾸지 않는다.

## 공유 이미지 생성 및 기존 LB 편집에서 발견한 실제 오류

프로젝트 소유 프로필 생성 시 일반 DeployVMCmd의 ACL이 프로젝트 공유 권한을 가진 이미지도 개인 호출자 권한으로 다시 거부했다. 프로젝트 프로필은 finalizeOwner 및 호출자의 프로젝트 접근 확인 후 기존 AS-06 소유자 기준 템플릿·Zone·오퍼링·네트워크·디스크·키·Affinity 검증을 적용한다. 프로젝트 외 프로필의 일반 dispatch 검증은 유지한다. API의 내부 배포 검증 map에는 확정된 프로젝트 ID를 전달하며 임의 소유자 파라미터로 덮어쓸 수 없다. 권한 없는 프로젝트 이미지 거부 회귀를 실행한다.

프로토콜이 없는 기존 LB 규칙을 알고리즘만 변경하면 서버가 null 프로토콜을 비교하며 실패했고, 일부 값은 먼저 저장됐다. 오토스케일 LB 편집은 누락 프로토콜에 기존 TCP 의미를 명시하여 저장하며 명시된 SSL/기타 프로토콜은 유지한다. 전용 규칙에서 실제 저장 및 복원을 확인한다. 네트워크 초기 VPC 조회의 중첩 params 오류도 AS 옵션에서만 평면 프로젝트 인자로 교정하여 기본 VM 요청 형식을 보존한다. 페이지 번호와 버튼 hover/focus를 동일한 테마 토큰으로 맞춘다. 일반 사용자 목록의 프로젝트 전환 스위치는 켜짐/꺼짐 배경과 글자를 함께 지정하여 반투명 배경의 낮은 대비를 제거하고 초점 표시를 보존한다.
