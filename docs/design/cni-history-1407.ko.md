# CNI 복제 이력·본문/변수 비교 설계 (#1407)

2026-10-18. Europa dc31262567f2afe5f6278fae61c1cef7e307fe3e, 누적 #1406 9d367758a43c1e007fb68e7c9677a4e758d76646 기준.

CNI 상세에 복제 이력 탭을 추가한다. #1406의 MOLD_CNI_CLONE/1 Annotation만 읽고 완전한 조각·schema/UUID·동일 소유 범위·현재 CNI 유형과 바이트 수를 다시 확인한다. 일반 코멘트와 일반 UserData 관계는 이력으로 추정하지 않는다. 메타데이터는 편집 가능한 보조 정보이며 보안/감사 증거가 아니다.

동일 계정/도메인 또는 프로젝트 CNI를 50개씩 최대200개 조회하고 (범위 밖 현재 구성의 직접 조회는 별도) 4개 동시 읽기로 각 CNI의 Annotation을 100개씩 최대500개 읽는다. 원본 방향의 추가 탐색은 최대16단계로 제한한다. 페이지 총계 변경·중복 UUID·빈 중간 페이지·잘못된 소유/응답을 완전한 목록으로 표시하지 않는다. 조회 상한은 제한 안내, 실패는 오류/재시도와 이전 결과 표시로 구분한다. 전체 범위가 확인되지 않으면 완전한 이력으로 주장하지 않는다.

현재 CNI의 원본·상위 원본·파생 구성을 연결하고 루트에서 파생 순서로 표시한다. 실제 타입/소유를 확인한 자원만 이름과 상세 링크를 표시한다. 삭제/권한 밖 원본은 UUID와 조회 불가 상태를 표시하고 링크/관계 비교를 막는다. 손상/불완전/길이 불일치 기록과 순환을 별도 표시한다. 무관한 손상/조회 불가 기록도 소유 범위 조회의 경고로 집계한다.

행의 원본과 비교 또는 접근 가능한 구성2개 선택 비교를 제공한다. 비교 시 현재 상세 CNI를 전후 재확인하고 양쪽 CNI를 소유 범위로 다시 읽어 실제 바이트/변수를 대조한다. 원본과 비교는 관계 기록도 다시 읽어 삭제/변경/불완전해진 관계를 차단한다. 동일/상이·첫 차이 바이트·본문 크기·선언 변수 추가/제거와 UTF-8 변경 구간을 표시한다. 선두/후미 동일 행을 제외한 변경 구간을 표시하며 최소 편집 경로를 주장하지 않는다. 최대500행/65536문자까지만 렌더링하고 제한 안내를 표시한다. 비 UTF-8은 바이트 비교·Base64/다운로드만 제공하고 텍스트 비교 불가를 표시한다. 손상 Base64/조회 불가/오류는 다른 상태다. 본문 전체 열람은 기존 공용 원문/Base64 컴포넌트를 사용한다. CNI/클러스터/관계 쓰기 API는 호출하지 않는다.

VM 공통 detail-tab-toolbar·작은 표·내부 가로 스크롤·페이지네이션·MoldDialog xl을 사용한다. 상시 기능/API 설명은 넣지 않는다. 동일 범위 갱신은 표를 유지하고 오류 시 이전 결과임을 안내한다. 대상/소유/세션/권한/탭 변경은 읽기 세대를 바꾸고 비교/내보내기 stale 응답을 차단한다. 상위 조회 실패를 빈 이력으로 표시하지 않고 상단 상세 갱신을 안내한다. ResourceView에 읽기 대기 상태만 전달하는 주입 계약을 추가해 백그라운드 조회 대기와 권한/식별 실패를 구분한다. 이미 시작된 상위 갱신이 비교와 겹치면 스냅샷/창을 유지하되 본문 내보내기를 잠그고, 완료 후 현재 CNI·양쪽 구성·필요한 관계를 다시 검증한다. 실패/범위 변경은 본문을 제거한다. 모달이 열린 뒤 전역 자동 갱신을 대기시키는 기존 규칙은 유지한다. 동일 범위 갱신에서 유효한 두 행의 선택도 보존한다.
