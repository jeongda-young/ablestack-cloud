# #1407 CNI 복제 이력·본문/변수 비교 — 31번 검증

2026-10-18. Epic #1395 / 누적 PR #1409. [설계](../../design/cni-history-1407.ko.md). 원본 Europa dc31262567f2afe5f6278fae61c1cef7e307fe3e, 누적 #1406 9d367758a43c1e007fb68e7c9677a4e758d76646 기준.

## 구현

CNI 상세의 **복제 이력**은 현재 구성·원본·파생 구성을 단계 순서로 표시한다. #1406의 CNI 전용 관계 조각을 완전한 집합으로 읽고 schema/UUID/유형/소유/현재 바이트 수를 검증한다. 일반 코멘트와 일반 UserData 관계는 CNI 이력으로 추정하지 않는다. 삭제/권한 밖/유형이 다른 원본은 UUID와 조회 불가 상태로 표시하며 링크·원본 비교를 막는다. 손상·부분·순환·실패·상한 도달을 별도로 표시한다. Annotation은 편집 가능한 보조 정보이며 보안 권한이나 서버 감사 기록을 대신하지 않는다.

계정/도메인 또는 프로젝트 범위를 명시해 50개씩 최대200개 CNI와 원본16단계를 탐색한다. 범위 밖 현재 구성은 직접 읽는다. 각 CNI의 코멘트는 100개씩 최대500개, 동시 읽기는4개다. 총계 변경·중복 UUID·빈 중간 페이지·응답 손상은 완전한 결과로 표시하지 않는다. 상한/미확인 기록 경고가 있으면 전체 이력으로 간주하지 않는다. 검색·페이지/크기·URL 복귀와 같은 범위의 유효한 두 행 선택을 보존한다. 실제 페이지 전환 검증에서 공용 상세의 fullPath 범위가 이력 페이지 변경을 대상 변경으로 처리해 선택을 지우는 결함을 확인했다. CNI 상세에서 이력 전용 page/size/query만 부모 조회 범위에서 제외하고, 부모 재조회를 생략한다. 대상 UUID·소유/프로젝트·그 밖의 조회 조건 변화는 기존 검증/초기화를 유지한다. 실제 a-table의 off-page 선택 테스트와 Autogen의 route/scope 통합 회귀를 추가했다.

**원본과 비교** 또는 **선택 구성 비교**는 현재 상세 CNI와 두 구성을 다시 읽어 본문 바이트·첫 차이 위치·크기·선언 변수의 동일/상이 및 추가/제거를 표시한다. 원본 비교는 관계도 다시 읽어 삭제/변경된 기록으로 비교하지 않는다. UTF-8은 선두/후미 같은 행을 제외한 변경 구간을 표시한다. 최소 편집 경로를 주장하지 않으며 최대500행/65,536문자 제한을 안내하고 전체 본문을 별도로 펼친다. 비 UTF-8은 바이트 비교와 Base64/다운로드, 손상 Base64는 비교 불가로 구분한다. CNI/클러스터/관계 쓰기는 실행하지 않는다.

## 실제 관계와 읽기 전용 대조

- 계정 원본→`cni1407-ui-v1`→`cni1407-ui-v2`, 프로젝트 원본→`cni1407-project-v1`→`cni1407-project-v2`를 실제 복제 UI로 등록했다. v1은 본문/변수 변경, 계정 v2는 본문을 유지하고 NEW→NEXT 선언만 변경했다.
- 계정의 두 API 페이지에는 동일 소유 범위 CNI가 빠짐없이 포함됐다. 계정 가족은 루트+분기20개+UI 복제2개=23개이며 이력의 두 UI 페이지/UUID/단계를 독립 파이썬 그래프와 대조했다. 프로젝트는 정확히3개 UUID다.
- 전용 CNI59개에 속한 API 코멘트814개와 일반 UserData 코멘트1개를 구분해 대조했다. 원본의 일반 코멘트203개(일반 UserData prefix 포함)는3페이지에 걸쳐 읽었지만 CNI 관계로 표시하지 않았다. 같은 관계의 동일 조각이 중복 저장된 실제 분기도 한 관계로 처리했다.
- 별도 구성의 실제 코멘트501개는 정상 빈 이력이 아니라 조회 범위 제한이다. 부분/잘못된 JSON 관계는 손상, 상호 참조2개는 순환으로 표시하고 비교를 막았다. 200개 CNI 상한·16단계·불안정/빈 페이지·중복 페이지와 동시 읽기 상한은 집중 테스트에서 확인했다. 200개 이상의 실제 CNI를 생성했다고 주장하지 않는다.
- 삭제된 원본, 다른 계정 원본, 일반 UserData UUID를 가리키는 관계를 실제로 준비했다. 동일 소유 범위의 typed CNI 조회만 사용하므로 접근 불가 원본의 이름/상세 링크가 나타나지 않는다.
- 본문은 UTF-8 BOM/CRLF/한글/이모지·달러/역슬래시를 포함한73바이트, 수정70바이트와 동일70바이트, 바이너리4바이트, 700행 큰 본문을 포함한다. 복사·다운로드도 원본 바이트와 일치했다. 큰 변경 구간은500행으로 제한하고 양쪽 전체 본문을 별도로 제공한다.
- 비교를 시작한 뒤 전용 CNI/UserData/Annotation의 API 및 DB 스냅샷을 다시 대조했다. 비교 경로의 UI 명령은 조회만 포함하며 기존 CNI3/Kubernetes7도 유지됐다. [읽기 전용 검증](readonly-proof.json). 전용 프로젝트 멤버 추가/회수/복구는 권한 시험용 API 조작으로 분리했다.

## 권한·오류·상태 전이

실제 일반 계정의 다른 계정 CNI 읽기는 거부됐다. 일반 Regular 프로젝트 멤버로 세 단계 이력과 본문을 조회한 뒤 해당 멤버십을 정상 API로 회수했다. 새 비교는 본문/내보내기 없이 거부됐고 재조회로 이전 이력이 제거됐다. 권한 복구 후 상위 상세를 다시 확인해 정상 이력을 읽었다. 이 시험에서 상위 상세 실패가 빈 이력으로 보이는 결함을 발견해 미확인 안내와 상단 갱신 경로로 수정했다.

일시 조회 실패는 같은 범위의 표를 보존하되 이전 결과와 비교 차단을 표시한다. 삭제/권한/식별 변경은 내용을 제거한다. 상위 조회 대기와 실패를 구분하는 작은 읽기 상태 계약을 ResourceView에 추가했다. 이미 시작된 상위 갱신과 비교가 겹치면 창/스냅샷을 유지하고 내보내기를 잠근 뒤 재검증한다. 이 겹침은 실제로 마운트한 컴포넌트의 native fieldset으로 시험했으며, 전체 페이지 재진입을 겹침 증거로 계산하지 않았다. 모달이 열린 동안 새 자동 갱신을 대기시키는 기존 전역 규칙은 유지한다. 범위/탭/세션 변경과 늦은 응답 차단은 집중 테스트에도 포함했다.

조회500·일시 부재·손상 Base64·관계 기록 변경은 해당 브라우저 요청만 주입해 재시도/구분을 검증했다. 전체 사이트를 끊거나 운영 데이터를 수정하지 않았다. 초기의 넓은 주입 패턴은 후속 읽기를 멈춰 취소/타임아웃을 만들었으므로 손상 비교 PASS로 계산하지 않았다. 대상/명령에 한정하고 추가 요청을 정상 재개한 격리 시험으로 판정했다. 모든 주입은 해제했다.

## UI와 Epic 최종 표준

공용 detail-tab-toolbar·작은 표·내부 가로 스크롤/페이지네이션·MoldDialog xl·본문 미리보기를 사용한다. 긴 이름/원본은 툴팁으로 전체 식별자를 제공하고 행 높이를 유지한다. 다크/라이트의 추가·삭제 색상은 공용 테마 토큰을 사용한다. 불필요한 상시 기능/API 설명을 넣지 않았으며 오류·미확인·범위 제한에서만 필요한 안내를 표시한다. 구성 개수에 ‘클러스터’ 문구가 나오던 초기 재사용 오류도 수정했다.

[전체 화면·VM 기준 대응 및 최종 점검표](epic-ui-final-matrix.ko.md). 최종 배포본의 새 이력/비교 대표8상태를 1440/1024/768/390px × 라이트/다크 **64조합**으로 점검했다. 전체 기능48체크·142개 DOM/화면 기록과 ko/en 도움말4개 화면을 남겼다. release- 접두사의 64개가 마지막 부모 URL 범위 보완까지 포함한 최종 번들이며, 초기·기존 기능 회귀 화면은 이름으로 구분한다. 그림 크기도 실제 뷰포트와 대조했다. 같은 크기·테마의 VM 기준 화면과 CNI 메뉴/기존 탭/팝업 회귀를 대조했다. 화면 가로 넘침·모달 좌우/푸터 이탈은 DOM으로 검사했고 실제 모바일/데스크톱 스크린샷도 검수했다.
