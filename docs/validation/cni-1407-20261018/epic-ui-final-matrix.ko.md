상시 불필요 설명/API 구현 문구는 추가하지 않았다. 조회 대기·권한/오류·제한·삭제 상태에 필요한 안내는 유지했다. 신규 모달의 닫기/ESC·키보드 포커스와 실제 복사/다운로드, 같은 범위 선택 보존, 비교 중 상위 조회의 내보내기 잠금을 확인한다. 기존 기능의 실제 실행 근거를 단순 화면 스모크로 대체하지 않는다. 최종 화면 목록·뷰포트/테마·DOM 측정과 기능48체크는 ui-evidence.json 및 screenshots/에 기록했다. 최종 번들 release- 대표64조합을 확인했고 페이지 간 선택 비교·Tab/ESC는 실제 UI로, 이미 시작된 부모 조회와 비교의 겹침·native fieldset 잠금은 마운트 컴포넌트 테스트로 검증했다. 원래 각 기능의 전체 상태/역할·게스트 실행은 기존 보고서 근거를 유지한다.
